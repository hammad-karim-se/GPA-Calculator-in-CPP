# GPA Calculator (C++)

A simple console-based GPA Calculator developed in C++ as a hands-on practice project to strengthen programming fundamentals and problem-solving skills.

## Features

- Calculate GPA based on grades and credit hours
- Supports standard letter grades (A, A-, B+, B, etc.)
- Validates user input for grades and credit hours
- Displays total grade points and final GPA
- User-friendly console interface

## Technologies Used

- C++
- Functions
- Loops
- Conditional Statements
- Input Validation
- Basic Formatting (`iomanip`)

## How It Works

The program asks the user to:

1. Enter the total number of courses
2. Input grade for each course
3. Enter credit hours for each course

The program then converts grades into grade points, calculates total grade points, and computes the final GPA.

## Supported Grades

| Grade | Grade Points |
